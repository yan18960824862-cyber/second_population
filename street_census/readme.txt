﻿工业物第二人口普查 · 星云普查台
================================================================

一键启动（推荐）
----------------------------------------------------------------
双击 start.bat
  · 无需安装任何软件（用 Windows 自带的 PowerShell 起本地服务）
  · 会弹出一个最小化的命令行窗口（本地服务器，用完关掉它即可）
  · 浏览器会自动打开 http://127.0.0.1:8643/
  · 端口被占用时会自动顺延尝试 8644-8652，不影响一键打开

手动启动（任选其一，适合 Mac / Linux）
----------------------------------------------------------------
  Windows : python serve.py 8643
            （或右键 server.ps1，选择「使用 PowerShell 运行」）
  Mac     : python3 -m http.server 8643
  然后浏览器访问 http://127.0.0.1:8643/

包内结构
----------------------------------------------------------------
  index.html     主站 · 星云普查台（星图 / 星表 / 现场站 三个视图）
  site/          原街景普查站（内容与逻辑未改动，作为子站嵌入主站）
  nebula/        主站资源（样式 / 星图引擎 / 星表数据 / 数据生成脚本）
  start.bat      一键启动脚本（双击即可）
  server.ps1     PowerShell 本地静态服务器（支持视频拖动所需的 Range）
  serve.py       Python 本地静态服务器（备选）
  readme.txt     本说明

看什么
----------------------------------------------------------------
  01 星图    75 个街道对象投影成一张城市星云图：
             亮度=制造能耗，点亮区间=出现时段，运动星带轨道
             左侧可拖动「历元扫掠」时间轴，看星点随车流点亮熄灭
  02 星表    可排序的普查总表（编号 / 类别 / 星等 / 能耗 / 置信度）
  03 现场站  原监控站原样嵌入；在星图中点一颗星，
             档案里按「→ 现场画面」可直接跳到该对象出现的帧

常见问题
----------------------------------------------------------------
  · 直接双击 index.html（file:// 方式）打不开轨迹数据与视频拖动，
    必须用 start.bat 走本地服务。
  · 关掉弹出的黑色命令行窗口 = 停止服务；下次再看就再双击 start.bat。
  · 修改了 site/ 里的轨迹数据后，在项目根目录运行：
    python nebula/build_catalogue.py   （重新生成星表快照）
  · 联网时主站会加载更精致的展示字体；离线打开会自动退回系统字体，
    不影响功能。
